# デスクトップ Claude へのパワポ作成プロンプト

---

以下の検証結果データをもとに、PowerPoint プレゼンテーションを python-pptx で作成してください。

## 依頼内容

Snowflake Cortex の音声処理機能（AI_TRANSCRIBE / AI_COMPLETE 等）を日本語音声で評価した PoC の結果をまとめたスライドを作成してください。
社内向けの技術報告資料を想定しています。

- **スライド数**: 12 枚（下記の構成に従う）
- **言語**: 日本語
- **スタイル**: シンプル・情報密度高め。グラフは横棒または棒グラフを優先
- **出力ファイル名**: `snowflake_audio_poc_result.pptx`

---

## python-pptx での実装注意点

- スライドサイズ: 16:9（Widescreen）
- フォント: 日本語対応フォント（Noto Sans JP または Meiryo）を使用
- テーブルにはヘッダー行に背景色（例：薄いブルー #DDEEFF）を設定
- 強調したい数値やポイントは赤または太字で目立たせる
- グラフは matplotlib で生成して画像として貼り付けるか、python-pptx の Chart 機能を使う
- スライド番号をフッターに入れる
- sample9 の外れ値（17.7%）はグラフ内で目立つ色（オレンジ等）で強調する

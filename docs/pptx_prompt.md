# デスクトップ Claude へのパワポ作成プロンプト

---

以下の検証結果データをもとに、PowerPoint プレゼンテーションを python-pptx で作成してください。

## 依頼内容

Snowflake Cortex の音声処理機能（AI_TRANSCRIBE / AI_COMPLETE 等）を日本語音声で評価した PoC の結果をまとめたスライドを作成してください。
社内向けの技術報告資料を想定しています。

- **スライド数**: 11 枚（下記の構成に従う）
- **言語**: 日本語
- **スタイル**: シンプル・情報密度高め。グラフは横棒または棒グラフを優先
- **出力ファイル名**: `snowflake_audio_poc_result.pptx`

---

## スライド構成と各スライドの内容

### スライド 1：表紙

- タイトル：**Snowflake Cortex 音声処理 PoC 検証結果**
- サブタイトル：AI_TRANSCRIBE / AI_COMPLETE 日本語評価
- 実施日：2026年10月

---

### スライド 2：検証の目的と全体フロー

**目的**
- Snowflake Cortex の音声処理機能を日本語業務音声で定量評価
- 精度・処理速度・コスト・機能制約の 4 軸で業務利用可否を判断する

**全体フロー（テキストで図示）**
```
音声ファイル (.m4a)
  → Snowflake ステージ (AUDIO_STAGE / SSE暗号化)
  → AI_TRANSCRIBE（文字起こし）
  → [アプローチA] AI_SENTIMENT + AI_SUMMARIZE
  → [アプローチB] AI_COMPLETE (llama3.1-70b)
  → 結果テーブル (AUDIO_POC スキーマ)
```

### スライド 7：Step 3 ― テキスト分析 アプローチ A vs B

**前提**：東京リージョン（AWS_AP_NORTHEAST_1）では AI_COMPLETE の音声マルチモーダル入力が未展開のため、AI_TRANSCRIBE のテキスト結果を入力として比較

## python-pptx での実装注意点

- スライドサイズ: 16:9（Widescreen）
- フォント: 日本語対応フォント（Noto Sans JP または Meiryo）を使用
- テーブルにはヘッダー行に背景色（例：薄いブルー #DDEEFF）を設定
- 強調したい数値やポイントは赤または太字で目立たせる
- グラフは matplotlib で生成して画像として貼り付けるか、python-pptx の Chart 機能を使う
- スライド番号をフッターに入れる
